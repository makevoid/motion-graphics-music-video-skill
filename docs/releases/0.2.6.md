# 0.2.6 — GPT Image 2.6 Sunburst

Character generation, identity revisions and keyframe edits now use `openai/gpt-image-2.6/sunburst/text-to-image` and `openai/gpt-image-2.6/sunburst/edit`. Both adapters explicitly send `quality: "high"` and `reasoning_effort: "high"`. PNG output, one image per request and the 2752 × 1536 default size are retained; callers can still override request options.

The [generation schema](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=openai/gpt-image-2.6/sunburst/text-to-image) and [edit schema](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=openai/gpt-image-2.6/sunburst/edit) were checked on 2026-11-06 for the matching animated-lesson adapter update. Rendering quality supports `auto`, `low`, `medium`, `high`, `xhigh` and `max`; reasoning effort independently supports `low`, `medium` and `high`. The edit endpoint requires `image_urls` and supports up to 16 references. The retained default dimensions satisfy the generation schema's size constraints.

The adapter classes are now `Fal::Models::GptImage26` and `Fal::Models::GptImage26Edit`. Existing generated projects keep their own runtime copy. When upgrading a copied runtime, update explicit model constants in `config/generations.rb` to these names. Existing media and receipts remain historical records.

Regression tests exercise both endpoints through the queue client's submit/poll/result path with mocked HTTP, verify high/high defaults and reference forwarding, and check that explicit quality, reasoning and size overrides create distinct requests. Pipeline tests verify generation and edit defaults together.

Validation on 2026-11-06: all 48 non-live tests passed, including media and Swift rendering, with the runtime's `.venv/bin` on `PATH`. The client, OpenAPI loader, model base and both image adapters match the animated-lesson implementation byte for byte; that implementation passed real generation and editing at 2752 × 1536 with high/high earlier the same day. No additional paid generation or audio/video E2E was run in this repository.
