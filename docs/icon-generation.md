# Plugin icon

The shipped [SVG icon](../.claude-plugin/icon.svg) uses editable shapes and gradients, with no embedded bitmap, external resources, scripts, fonts, or metadata. It is 256×256 and displayed at 128×128 in the README.

The original raster icon and its large pixel-path SVG conversion have been replaced with this compact vector source. The prompt below is retained for optional raster recreation in a separate workspace. Generation is not part of plugin installation or startup; follow the project's generation budget and authorization before making a paid call. Generated images remain outside the plugin repository.

Original generation settings: the repository's `Fal::Models::NanoBanana2` adapter, endpoint `fal-ai/nano-banana-2`, `thinking_level: high`, one 2048×2048 PNG (`resolution: 2K`, `aspect_ratio: 1:1`). Request ID: `01a0df1d-5db4-7ad2-a483-749410e335e7`. Regeneration produces a new interpretation, not an identical copy. For a local thumbnail, resize the result to 256×256 and strip metadata.

## Generation prompt

Create a single square mobile app icon for a music video creation plugin: a chat bubble in iOS glassmorphism style, inside a rounded square frame made of frosted glass. Monochromatic orange palette only, from deep burnt orange to luminous pale orange, against a pure black background. Inside the chat bubble, show a simple video editing timeline with a clear play triangle integrated into it. Place a tiny musical note in the top right corner of the icon. Soft top-down lighting, translucent frosted glass layers, refined glossy orange edge highlights, subtle depth and shadows. High-resolution UI icon, polished Dribbble-trending design quality. Straight-on centered composition with safe padding, bold readable forms at small sizes. No words, letters, numbers, watermark, extra icons, phone mockup, or surrounding interface. One finished icon fills the square image.

## Example video thumbnails

The [README video list](../README.md#videos-created-with-this-skill) keeps the six source video links and credits. To recreate a thumbnail for a separate presentation or local preview, open the corresponding video, select a representative frame, and export a 16:9 JPEG without metadata. These are video stills, so use a frame from the source video instead of an image-generation prompt. Keep the exported files outside this repository; the plugin does not fetch them automatically.
